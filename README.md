# 诊后助手（Revisit Helper）

> 以复诊周期为单位的诊后信息与行动管理系统 · 温州医科大学黑客松参赛作品

## 定位

面向处于**上次就诊（或出院）结束到下次复诊之间**这段时间的患者，把医嘱执行、变化记录和复诊沟通组织在同一个流程里。

- **核心能力**：承接医生已有的安排（整理为可核对的行动卡），保存患者在两次就诊间发生的事情，最终形成可核对、可带进诊室的沟通材料。
- **场景**：骨科术后出院至复诊（主场景）＋高血压等慢病随访（扩展验证场景）。
- **对象**：术后出院患者（周期 2-4 周）；定期复诊的慢病患者（周期 1-3 个月）。
- **设计标准**：适老化（正文 17-19px、按钮 48px、状态文字化、图标带文字、支持家属代记与语音记录）；演示与测试使用老年人物设定。

## 功能

1. **医嘱行动卡**（四类固定结构：用药 / 复查 / 康复禁忌 / 就医提示）——内容全部来自用户提供的医嘱材料或本人录入，逐项核对后生效，来源原文随时可查；推算日期标注依据并请用户核对
2. **监测记录工具**（血压 / 体重 / 疼痛评分，纯记录、无建议、无每日推送）
3. **记一件事**（支持语音保存原话）
4. **待问清单** ＋ 出院前该问医生的问题模板（帮患者问得完整，不代医生回答）
5. **疑问分类处理**：流程类 / 科普类问题提供带来源的信息整理；判断类问题（是否正常、要不要紧）一律不回答，转为待问与已核实就诊渠道——**全部医疗判断保留给医生**
6. **复诊沟通卡**（本人逐项核对后生成；诊室模式放大字号、待问问题逐条勾选）
7. **周期归档**（复诊后停止本轮全部软件提醒，不表示治疗结束）

## 合规声明

- 不输出诊断结论，不给出用药方案，不替代专业意见
- 本仓库全部演示数据为**合成虚构**（陈淑兰、周建国均为虚构角色，电话号码为占位符）
